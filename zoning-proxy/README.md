# 브이월드 점포 좌표 조회

1. 브이월드에서 서비스 도메인 `https://kayla0401.github.io`의 오픈API 키를 발급합니다. 서버 요청에서 도메인이 허용되는지 실제 응답으로 확인합니다.
2. `zoning-proxy`에서 `npx wrangler deploy`로 Worker를 배포하고 `npx wrangler secret put VWORLD_API_KEY`의 입력창에 키를 입력합니다. 로컬 테스트에는 무시 처리된 `.dev.vars`를 사용할 수 있습니다.
3. 배포 URL의 `/zoning`에 `GET`으로 `lng`, `lat`를 전달하고 `Origin: https://kayla0401.github.io`를 보냅니다. 토지이음에서 용도지역을 확인한 상업지역·준주거지역 점포 좌표를 각각 비교합니다. 브이월드 데이터 API의 레이어 이름, 속성명, 도메인 허용 및 좌표 순서도 이때 검증합니다.
4. 검증한 HTTPS 프록시 URL을 루트 `zoning-config.js`에 설정합니다. GitHub Pages에서 점포 선택 및 핀 이동 시 자동조회가 시작되고 이중 조례 기준이 예비 참고용으로 표시되는지 확인합니다.

프록시는 고정된 용도지역 레이어 4개만 조회하며 조회 빈도를 제한합니다. 허용 Origin 검사는 브라우저 공유 정책에 사용됩니다. 외부 호출자가 Origin을 위조할 수 있으므로 운영 시 쿼터도 모니터링합니다.

## 직접 그린 구역

용도지역 도형을 구역의 경계 상자로 페이지 끝까지 수집하고, 중복 피처를 제거합니다. 신청 구역과 도형을 동일한 면적용 좌표계에서 교차한 뒤 상업·비상업별 합집합 면적을 구합니다. 미분류, 자료 누락, 분류 간 중첩은 따로 표시합니다. 고시 도면과 비교하고 관할 조례의 혼합 구역 처리 기준을 확인한 뒤 참고 비율을 표시할 수 있습니다. 점포 핀 조회로 신청 구역의 면적 비율을 추정하거나 판정하지 않습니다.
